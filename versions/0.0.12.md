# tach 0.0.12

Incremental release on top of 0.0.11 (reference: [0.0.11.md](0.0.11.md)). x86 only; ARM and RISC-V work is planned for 0.9 (see ROADMAP.md).

## Changes

- `/dev/null` and `/dev/zero`.
- `/dev/<disk>` entries (`hda`, `hda1`, ...) for every device in the block layer registry: raw byte-level read/write, listed by `ls /dev`, `stat` reports a block device with its size.
- `/proc/mounts`; `mount` with no arguments prints it.
- Ctrl+D (0x04) on the console ends input (`read()` returns 0).
- Userspace shell: `;`, `&&`, `||` (operators as separate words) and `$?` (as a separate word).
- `mkdir -p`.
- `syscalls` / `/proc/syscalls` list mkdir, rmdir, rename, sync, mount, umount.
- README: removed the non-existent `make all-archs`.

## Not verified

- Nothing was booted in the build environment (no QEMU / grub-mkrescue). Host tests and x86_64 kernel + userland builds pass.
- Whether the PS/2 keyboard driver delivers Ctrl+D as 0x04 (serial does).
- Raw writes to `/dev/<disk>` go through the block cache with no permission checks yet.
