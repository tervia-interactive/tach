# tach versions

One document per released version. Each document describes that version only: what it contains, how to build and run it, every command and tool shipped with it, and its known limitations.

| Version | Status | Document |
|---------|--------|----------|
| 0.0.11  | Current | [0.0.11.md](0.0.11.md) |

Conventions:

- File name is the version number: `<major>.<minor>.<patch>.md`.
- A version document is not rewritten when a newer version ships; the newer version gets its own file.
- For the direction of the project, see [ROADMAP.md](../ROADMAP.md). For a quick start, see [README.md](../README.md).
